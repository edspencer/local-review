---
title: Installation
description: Run Local Review with npx, install it globally, or run it from a clone.
---

Local Review is a Node.js app that runs on your own machine. You can run it on demand with `npx local-review`, install it globally with `npm install -g local-review`, or clone the repo and run it from source. macOS and Linux are supported; Windows is untested.
