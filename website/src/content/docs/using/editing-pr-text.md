---
title: Editing PR titles & descriptions
description: Override a PR's title and description without touching the commit.
---

You can rewrite a PR's title and description in place. The edits are saved to the PR's `prs/` file, never to the commit, and the copy buttons give you exactly the text to paste into the real GitHub PR, project context included.
