title: A tour of the UI
description: The header, sidebar, PR header, tabs and project homepage, and what each shows.
---

Local Review mirrors GitHub's pull-request page, under a deliberately un-GitHub plum and amber header. The sidebar lists each repo's stacks and PRs with their readiness badges; each PR has Conversation, Files changed and Stack tabs; and each project has a homepage with its intro and a picture of every stack.
