title: Stack pictures
description: A PNG of your stacks, weighted by size, to paste next to a PR or into chat.

The **Stack** tab and each project homepage draw a picture of the project's stacks, with every PR's size on one shared scale and the current PR highlighted. Copy it as an image or download a PNG to paste beside a real PR or into Slack.
