---
title: The plan command
description: Print what each PR should be on GitHub, without changing anything.
---

`local-review plan <project>` prints the read-only **materialization plan**: for each PR, its branch, its base and its full title and body, as Markdown, JSON or YAML. An agent follows it to publish the stacks.
