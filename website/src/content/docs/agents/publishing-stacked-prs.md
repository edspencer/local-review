---
title: Publishing as GitHub stacked PRs
description: Turn reviewed stacks into GitHub's native stacked pull requests.
---

When a stack is ready, an agent pushes its branches, opens one PR per commit with the plan's titles and bodies, links them into a GitHub stack and records each PR back in Local Review. Local Review itself never talks to GitHub.
