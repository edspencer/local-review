---
title: Comment files
description: Your review lives in YAML files an agent can read and reply to.
---

Each PR's threads live in `reviews/<repo>/<full-sha>.yaml`. An agent replies by appending a comment with `author: claude`, and the reply shows up in the browser live. Threads follow their code across amends and rebases.
