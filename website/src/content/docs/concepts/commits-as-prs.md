---
title: Commits as PRs
description: Every commit in a range is reviewed as if it were its own pull request.
---

In Local Review each commit is one candidate **PR**, with a Conversation tab and a Files changed tab, just like a GitHub pull request. PRs are numbered across the whole repo, oldest first, and keep their numbers as their stack lands.
