---
title: 'Readiness: draft, ready, published'
description: Each PR moves from draft to ready to published, and finally merged.
---

Every PR carries one **readiness** state: a **draft** while you are still reviewing it, **ready** once you mark it so, **published** once an agent records the GitHub PR it created, and **merged** once it has landed. The sidebar badge and the stack's `2/4 READY` count show where a stack stands at a glance.
