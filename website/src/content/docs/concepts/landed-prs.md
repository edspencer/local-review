---
title: Landed PRs
description: Merged PRs stay in their stacks instead of vanishing when the base moves.
---

Once a stack's PRs merge on GitHub, their commits leave the live range. An agent **freezes** each merged PR into a `landed:` record first, so it stays in its stack, keeps its number, and still shows the diff GitHub merged.
